🚀 ExpoVerse – Student Expo Management Platform

ExpoVerse is a full-stack platform that connects university students, companies, and visitors through a digital exhibition experience. It enables students to showcase their projects, companies to discover emerging talent, and administrators to manage exhibition activities.

✨ Key Features
🎓 Student Portal
Create and manage student profiles.
Showcase projects with images, videos, and documents.
Collaborate with other students.
Explore internship and job opportunities.
Communicate with companies.
Receive project feedback and ratings.
🏢 Company Portal
Discover talented students and explore their projects.
Publish internship and job opportunities.
Evaluate student projects and provide feedback.
Communicate directly with students.
🛠️ Admin Dashboard
Manage student, company, and visitor accounts.
Review and approve submitted projects.
Verify company accounts.
Manage exhibition booths and interactive maps.
Monitor platform activities.
🤖 AI & RAG Integration
Retrieval-Augmented Generation (RAG) capabilities.
Context-aware information retrieval.
AI-powered responses based on relevant project information.

Note: Confirm the specific RAG pipeline, embedding model, vector database, and LLM against the implementation before publishing.

🌐 Additional Features
Secure authentication and email verification.
Real-time communication.
Cloud-based file storage.
Responsive web and mobile applications.
Interactive exhibition booth mapping.

Component	Technologies

Mobile	React Native, Expo

⚙️ Getting Started
Prerequisites
Node.js
npm
MySQL
Expo development environment
Required Firebase and AWS credentials
Clone Repository
bash
git clone https://github.com/Ayman-AbuHijleh/Expo-Verse.git
cd Expo-Verse

Backend
bash
cd backend
npm install


Configure environment variables and database credentials before starting the backend.

Web Application
bash
cd web
npm install
npm run dev

Mobile Application
bash
cd mobile
npm install
npx expo start

🎯 Project Objective

ExpoVerse aims to bridge the gap between academic education and industry by providing students with a digital space to present their innovations, connect with companies, receive professional feedback, and discover career opportunities.
